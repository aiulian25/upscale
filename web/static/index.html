            Models

            To add a model, copy its .pth or .safetensors file into data/models and restart the app. Photo models that upscale 2× or 4× join the Model picker; any other file is listed below with the reason. When a model comes in both formats, take the .safetensors: it holds nothing but weights.

            Where to find models:

            • OpenModelDB: the community catalogue, here filtered to photos, with before and after images
            • Philip Hofmann's models: photo models, including the built-in Nomos8kSC
            • Kim2091 on Hugging Face: the built-in UltraSharp and its successor, UltraSharp V2
            • Real-ESRGAN releases: RealESRGAN_x2plus.pth, a 2× model by the makers of the built-in x4plus
            • spandrel's architecture list: the kinds of model the app can run
